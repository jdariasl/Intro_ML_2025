# U5. MODELOS DE ÁRBOLES Y ENSAMBLES

## Árboles de decisión

**31 - Árboles de decisión para clasificación**: [Video 21mins]() <br/> Se presenta la intuición detrás de los árboles de decisión, el concepto de impureza y la manera en la que se puede medir, así como la función criterio en este caso conocida como ganancia de información. También se discuten algunos de los hiperparámetros más relevantes de los modelos de árboles de decisión.

**32 - Árboles de decisión para regresión**: [Video 21mins]() <br/> Se presenta la extensión del modelo de árboles de decisión a problemas de regresión. Se discuten las capacidades de los modelos basados en árboles de abordar problemas de múltiples salidas o múltiples tareas.

## Comités de máquina

**33 - Comités de máquinas y bagging**: [Video 21mins]() <br/> Se introduce el concepto de comité de máquinas y se presentan las técnicas de combinación paralela más conocidas: voting y bagging.

**34 - Random Forest**: [Video 21mins]() <br/> Se presenta una variante de la técncia Bagging específica para modelos de árboles de decisión conocida como Random Forest.

**35 - Boosting y AdaBoost**: [Video 21mins]() <br/> Se introduce la técnica de combinación de modelos secuencial conocida como Boosting y uno de los algoritmos clásicos que hacen uso de ésta. 

**36 - Gradient Boosting Trees**: [Video 21mins]() <br/> Se introduce una variante del Boosting conocida como Gradient Boosting y su implementación a partir de árboles de decisión. 

**37 - Isolation Forest**: [Video 8mins](https://youtu.be/MfxdckSCWwk) <br/> Se presenta un modelo basado en comités de árboles de decisión que permite abordar problemas de clasificación de una clase o de detección de anomalías y su uso en un conjunto de datos simulado.
